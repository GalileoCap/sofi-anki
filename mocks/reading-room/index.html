What is event bubbling?

When an event fires on an element, it propagates upward through ancestor elements in the DOM.

// Listener on #parent fires after #child's listener
child.addEventListener('click', e => { /* fires first */ });
parent.addEventListener('click', e => { /* fires second */ });
  • event.stopPropagation() stops bubbling
  • event.target is the element originally clicked
  • event.currentTarget is the element the listener is on
