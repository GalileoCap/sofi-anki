What is a closure?

A function that retains access to its enclosing scope's variables even after the outer function has returned.

function makeCounter() {
  let count = 0;
  return () => ++count;
}
const inc = makeCounter();
inc(); // 1

Closures power data privacy, partial application, and memoization.
